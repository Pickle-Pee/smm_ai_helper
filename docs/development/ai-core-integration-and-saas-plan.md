## 4. Переход к SaaS

Цепочка: B1a Identity (#203) → B2 Authentication & Sessions → B3 Organizations & Memberships → B4 Projects & Brands → B5/B6 Web API Copilot Integration.

### Можно ли начинать B2 сейчас — да, с условиями

- **Миграции:** единственная новая миграция в работе — 0015 (B1a). B2 добавляет `20261118_0016_*` с `down_revision = "20261114_0015"` и ветвится от #203. Ни доставка, ни CMO stabilization миграций не добавляют, конфликта голов Alembic нет. Правило: до merge B1a в master никакая другая ветка не добавляет миграцию от 0014.
- **AI Core не затрагивается:** B2 работает в `app/routers` (новый auth router), `app/services` (сессии), `app/security.py`, `app/models.py` (таблицы сессий); не меняет `app/module_execution`, `app/orchestration_runtime`, `app/marketing_copilot`.
- **Telegram-совместимость:** бот продолжает использовать `BOT_BACKEND_TOKEN` + `X-Telegram-User-ID`; B2 добавляет второй способ аутентификации (web-сессия), не заменяя первый. Для пользователей без `telegram_id` автоматическая доставка уже пропускает уведомление (условие в `_queue_run_notice`), web получит свой канал в B5/B6.
- **Что можно делать до merge стека:** дизайн сессий (cookie vs bearer, ротация, отзыв, срок жизни), модель угроз, контракт API `/auth/*`, тесты сервисного слоя на PostgreSQL. Merge B2 — только после B1a.
