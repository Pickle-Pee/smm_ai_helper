# Database migrations

Проект использует Alembic для управления схемой БД.

## Новая пустая БД

```bash
alembic upgrade head
```

После этого можно запускать backend.

## Уже существующая MVP-БД

Если таблицы уже были созданы старым механизмом `Base.metadata.create_all`, то первую baseline-миграцию не нужно применять поверх существующих таблиц.

В этом случае нужно один раз пометить текущую БД как актуальную:

```bash
alembic stamp head
```

После этого все следующие изменения схемы применяются обычной командой:

```bash
alembic upgrade head
```

## Важно

Backend больше не создает таблицы автоматически на startup. Это сделано намеренно, чтобы изменения схемы были явными и контролируемыми.
